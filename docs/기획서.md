# 미팅 링고 패드 (Meeting Lingo Pad) 기획서

작성일: 2026-08-06 · 상태: v0 (Claude 아티팩트) 배포 완료, v1 웹 서비스 예정

## 1. 배경 / 문제 정의

- 해외 화상미팅은 주로 영어로 진행되는데, 비원어민이라 회의 중 단어가 떠오르지 않거나
  표현 방법을 모르는 순간이 생긴다. 회의 중에는 사전을 찾을 여유가 없다.
- 기존 도구(Smooth 등)는 실시간 번역·회의 기록은 지원하지만, **말하는 순간의 단어/표현 제시**는
  지원하지 않는다.
- 목표: 회의 중 **한 페이지에서 조용히 참고**할 수 있는 언어 보조 패드.

## 2. 핵심 기능 (요구사항)

| # | 기능 | v0 (아티팩트) | v1 (웹) |
|---|------|--------------|---------|
| 1 | 출발어/도착어 설정 | ✅ 셀렉터 + 스왑 (내장 사전은 한↔영) | 다국어쌍 전면 지원 |
| 2 | 아젠다 전체 번역 (별도 탭) | ⚠️ Claude 채팅에 붙여넣으면 번역본을 구워서 재배포 | 업로드 즉시 AI 번역 |
| 3 | 아젠다 원문 단어 마우스오버 툴팁 | ✅ 내장 사전(약 300 용어) 기반 하이라이트+툴팁 | AI 형태소/문맥 기반 전 단어 |
| 4 | AI 분석 어휘 제안 탭 | ⚠️ 기본 비즈니스 어휘 제공, 아젠다 공유 시 맞춤 어휘로 교체 | 실시간 AI 분석 |
| 5 | 검색바 (언어 자동 감지) | ✅ 한/영 자동 감지 + 내장 사전 즉시 조회 + Google 번역/Papago 새 탭 연동 | 번역 API 직접 연동 |
| + | 긴급 회의 표현 모음 | ✅ 7개 카테고리 40여 문장, 클릭 시 복사 | 개인화(자주 쓰는 표현) |
| + | 설정/아젠다 로컬 저장 | ✅ localStorage | 계정 기반 저장 |

## 3. v0 아키텍처 (아티팩트)

- 단일 자급자족 HTML. 아티팩트 CSP상 외부 API 호출 불가 →
  - 내장 한↔영 비즈니스 사전(EN→KO 약 220, KO→EN 약 100 항목)
  - 외부 번역은 URL 프리필 링크(새 탭)로 우회: Google Translate, Papago
  - AI 번역/어휘 분석은 **채팅에서 Claude가 수행 → `BAKED` 상수에 주입 → 재배포** 하는 베이크 방식
- 배포 URL: https://claude.ai/code/artifact/2f136649-6f0e-432e-8ebf-3ced1b3a4c3c
- 소스: 세션 스크래치패드 `meeting-lingo-pad.html` (재배포 시 동일 URL 유지)

### UI 구성 (한 페이지, 회의 중 산만하지 않게)

1. 상단 고정 검색바 — 언어 자동 감지 칩, 사전 결과 즉시 표시, 외부 번역기 링크
2. 탭: `긴급 표현` / `아젠다 원문(툴팁)` / `전체 번역` / `어휘 제안`
3. 라이트/다크 테마 토큰 기반 지원, 클릭-복사 인터랙션

## 4. v1 웹 서비스 로드맵 (추후)

1. **스택**: Vite + React(or Svelte) + 서버리스 함수(번역·AI 프록시) — API 키 은닉 필수
2. **번역**: 문서 전체 번역(문단 단위), 단어 정렬(word alignment) 기반 툴팁
3. **AI 어휘 제안**: Claude API로 아젠다 분석 → 도메인 용어, 발음 주의 단어, 예문
4. **검색**: 번역 API + 사전 API(예: Wordnik/국립국어원) 병행, 검색 히스토리
5. **부가**: 회의 중 메모, 표현 즐겨찾기, PWA(오프라인 사전), 단축키(⌘K 검색)

## 5. 성공 기준

- 회의 중 3초 내에 원하는 단어/표현에 도달
- 화면 전환 없이(탭 1회 이내) 참고 가능
- 아젠다 기반 사전 준비(번역본+어휘)를 회의 전 5분 내 완료
