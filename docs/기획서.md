# 미팅 링고 패드 (Meeting Lingo Pad) 기획서

작성일: 2026-08-06 · 상태: **v1 웹 앱(`web/index.html`) 완성** — 실시간 번역 API 연동. v0 아티팩트는 참고용으로 유지

## 1. 배경 / 문제 정의

- 해외 화상미팅은 주로 영어로 진행되는데, 비원어민이라 회의 중 단어가 떠오르지 않거나
  표현 방법을 모르는 순간이 생긴다. 회의 중에는 사전을 찾을 여유가 없다.
- 기존 도구(Smooth 등)는 실시간 번역·회의 기록은 지원하지만, **말하는 순간의 단어/표현 제시**는
  지원하지 않는다.
- 목표: 회의 중 **한 페이지에서 조용히 참고**할 수 있는 언어 보조 패드.

## 2. 핵심 기능 (요구사항)

| # | 기능 | v1 웹 (`web/index.html`) — 현재 |
|---|------|--------------------------------|
| 1 | 출발어/도착어 설정 | ✅ 7개 언어 셀렉터 + 스왑, localStorage 저장 |
| 2 | 아젠다 전체 번역 (별도 탭) | ✅ [번역 + 분석] 클릭 시 문단 단위 청크 번역 → 전체 번역 탭 |
| 3 | 아젠다 원문 단어 마우스오버 툴팁 | ✅ 모든 단어(영문·한글 토큰) 자동 래핑, 호버 시 사전 → 실시간 번역 순으로 조회(캐시) |
| 4 | AI 분석 어휘 제안 탭 | ✅ 기본: 빈도 기반 추출 + 자동 번역 / API 키 입력 시: **Claude(claude-opus-5) 문맥 분석**(그룹·뜻·예문) |

| + | 긴급 회의 표현 모음 | ✅ 7개 카테고리 40여 문장, 클릭 시 영어 문장 복사 |
| + | 로컬 저장 | ✅ 아젠다/번역본/어휘/언어쌍/API 키 → localStorage |

## 3. v1 아키텍처 (웹)

- **정적 단일 HTML** (`web/index.html`) — 빌드·서버 불필요, 더블클릭(file://)으로도 동작
- **번역 엔진**: Google 번역 비공식 gtx 엔드포인트 (`translate.googleapis.com/translate_a/single?client=gtx`)
  - 무료·키 불필요·CORS 허용. 비공식이므로 향후 차단 가능성 있음 → 차단 시 공식 API 프록시로 교체
- **AI 어휘 분석(선택)**: 사용자의 Anthropic API 키(설정 ⚙, localStorage 저장)로 브라우저에서 직접 호출
  - `POST /v1/messages`, 모델 `claude-opus-5`, `anthropic-dangerous-direct-browser-access` 헤더,
    `output_config.format`(json_schema)으로 구조화 응답 수신
- **오프라인 즉답 레이어**: 내장 한↔영 비즈니스 사전(약 320 항목) — 사전 히트 시 API 호출 없이 즉시 표시

### UI 구성 (한 페이지, 회의 중 산만하지 않게)

1. 상단 고정 검색바 — 감지 언어 칩, 즉시 번역 결과(클릭=복사), 사전 결과, 외부 번역기 링크
2. 탭: `아젠다 원문(툴팁)` / `전체 번역` / `어휘 제안` / `긴급 표현`
3. 라이트/다크 테마(OS 설정 따름), 클릭-복사 인터랙션

## 6. 성공 기준

- 회의 중 3초 내에 원하는 단어/표현에 도달
- 화면 전환 없이(탭 1회 이내) 참고 가능
- 아젠다 기반 사전 준비(번역본+어휘)를 회의 전 5분 내 완료
