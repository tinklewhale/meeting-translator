# 작업 스킬 / 운영 규칙

이 저장소에서 Claude가 작업할 때 따르는 규칙과 필요 스킬 목록.

## 오케스트레이션

- **오케스트레이터**: Fable 5 (메인 세션)
- **서브 에이전트**: Opus (`Agent` 툴 호출 시 `model: "opus"` 지정)
  - 대상 작업: 대량 사전 데이터 생성, 아젠다 번역/어휘 분석, v1 웹 구현 병렬 작업
- 단, v0 아티팩트처럼 단일 파일 규모 작업은 서브 에이전트 없이 메인에서 직접 처리

## 문서 유지

- 기능/구조 변경 시 [기획서.md](기획서.md)와 이 문서를 같은 커밋에서 갱신
- 아티팩트 재배포 시 기획서의 배포 URL/버전 표기 확인

## 커밋 / 푸시

- 의미 단위 작업 완료 시 자동 커밋 (한국어 요약 + 상세)
- 원격(remote)이 설정되어 있으면 자동 push, 없으면 로컬 커밋만 하고 사용자에게 안내

## v0 아티팩트 운영 플로우

1. 사용자가 채팅에 회의 아젠다 붙여넣기
2. Claude가 전체 번역 + 맞춤 어휘 분석 수행
3. `meeting-lingo-pad.html`의 `BAKED = { translation, vocab }`에 주입
4. 동일 URL로 아티팩트 재배포 (Artifact 툴, 같은 파일 경로)

## 필요 스킬 (Claude Code 기준)

| 스킬 | 용도 |
|------|------|
| `artifact-design` | 아티팩트 페이지 디자인 가이드 (배포 전 필수 로드) |
| `artifact-capabilities` | 아티팩트 런타임 기능 확인 (현재 downloads, mcp만 가용 — AI 호출 불가) |
| `frontend-design` 계열 | v1 웹 UI 구현 시 |
| `claude-api` | v1에서 Claude API(번역/어휘 분석 프록시) 연동 시 참조 |
