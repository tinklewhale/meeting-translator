회의가 끝나면 Claude가 기록을 분석해 요약·결정 사항·액션 아이템·영어 표현 교정·학습 어휘를 만들어 줍니다. 학습 어휘에는 뉘앙스 차이, 어떤 상황에서 쓰는지, 예문, 비슷한 표현 비교가 포함됩니다. (설정 ⚙에 API 키 필요)

AI 기능 설정

Anthropic API 키를 입력하면 어휘 제안·답변 제안·영어 작문·회의 리포트를 Claude(claude-opus-5)가 수행합니다. 모든 영어 출력에는 영국식 · 직역 금지(자연스러운 비즈니스 표현) · professional-warm 톤 규칙이 적용됩니다. 키는 이 브라우저의 localStorage에만 저장되며 Anthropic API 호출 외에는 전송되지 않습니다.
